# 💬 Random Quote Generator

A minimal web app that displays a random inspirational quote at the click of a button. This project was completed as **Task 2** of my App Development Internship at **CodeAlpha**.

## ✨ Features
- Displays a random quote with its author every time the app loads or the button is clicked
- **"New Quote"** button generates a fresh quote instantly
- Clean, minimal UI focused on readability

## 🛠️ Built With
- HTML
- CSS
- JavaScript (vanilla, no frameworks)

## 🚀 How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser
3. Click **New Quote** for a dose of inspiration!
